# Security Policy

## Supported Versions

We prioritize the security of our Linux desktop mods and extensions. The table below lists currently supported versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `ubuntu-custom-mods` or any of its sub-modules (`clippaste`, `nautilus-copy-path`), please do **not** open a public issue.

Instead, please send an advisory email directly to:

📧 **quyettu347@gmail.com** (Duy Phan - `@duyphan0503`)

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof of concept (PoC).
3. Potential impact on the host system or user session.
4. Suggested mitigation or patch (if available).

We will acknowledge receipt of your vulnerability report within 48 hours and work with you on a resolution prior to any public disclosure.
